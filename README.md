# PgwToRos2Yaml

> **QGIS World File (`.pgw`) ⇄ ROS / ROS 2 (Nav2) `map.yaml` Converter**  
> QGIS等のGISソフトウェアから出力されたワールドファイル（PGW形式）と地図画像情報をもとに、ROS / ROS 2 の `map_server`（Nav2等）で使用する `map.yaml` を自動計算・出力するスタンドアロンWebツールです。

---

## 📌 概要

屋外自律移動ロボットや測量・GIS連携において、QGIS等で作成した高精度なオルソ画像や地図データ（UTM座標系等）を ROS / Nav2 のコストマップや地図サーバーに読み込ませる際、**PGWファイルと ROS `map_server` の原点定義の違い**による座標のズレが頻繁に問題となります。

本ツールは、HTML / CSS / JavaScript が1ファイルに内包された**完全スタンドアロン構成**（外部サーバー・追加ビルド手順不要）であり、ブラウザで `index.html` を開くだけで即座に使用可能です。

---

## 📐 座標系と原点の変換仕様（数学的根拠）

### 1. PGWファイル（ワールドファイル）の構造（6行）

| 行 | パラメータ | 説明 | 典型的な値 |
|:---:|:---:|:---|:---|
| 1 | $R_x$ | X方向のピクセル解像度 [m/pixel] | `0.05` |
| 2 | $A$ | 回転パラメータ（通常 0） | `0.0` |
| 3 | $B$ | 回転パラメータ（通常 0） | `0.0` |
| 4 | $R_y$ | Y方向のピクセル解像度（上から下へ進むため通常**負値**） | `-0.05` |
| 5 | $X_{\text{pgw}}$ | **左上ピクセル中心**のX座標（UTM Easting等 [m]） | `392500.025` |
| 6 | $Y_{\text{pgw}}$ | **左上ピクセル中心**のY座標（UTM Northing等 [m]） | `3954200.025` |

### 2. ROS / ROS 2 (Nav2) `map_server` の原点定義

- `resolution`: ピクセルあたりの実距離（正値・通常 $|R_x|$）
- `origin`: 画像の**「左下ピクセル」の「左下外側角（境界）」**の座標 $[origin\_x, origin\_y, yaw]$

```
[PGWの基準点]
(X_pgw, Y_pgw) ─── 左上ピクセル中心
      │
      │ ＋0.5 * |Rx| (左端境界へ半ピクセル戻す)
      ▼
┌──────────────┐
│  左上ピクセル  │ ...
├──────────────┤
│              │
│   地図画像    │ 高 さ H (pixels)
│              │
├──────────────┤
│  左下ピクセル  │ ...
└──────────────┘
▲
│
[ROS map_server の基準点]
origin = (origin_x, origin_y) ─── 左下ピクセル外側角 (境界)
```

### 3. 変換計算式

画像の幅を $W$、高さを $H$（ピクセル単位）とした場合：

$$origin\_x = X_{\text{pgw}} - \frac{|R_x|}{2}$$

$$origin\_y = Y_{\text{pgw}} - (H - 0.5) \times |R_y|$$

$$origin = [origin\_x,\ origin\_y,\ 0.0]$$

> **【補足】Y方向の導出理由**:
> 1. 左上ピクセル中心 ($Y_{\text{pgw}}$) から 左下ピクセル中心 までは $(H - 1)$ ピクセル下方に移動します。
> 2. 左下ピクセル中心 から さらに 左下ピクセルの外側角（下端境界） までは $0.5$ ピクセル下方に移動します。
> 3. したがって、合計移動量は $(H - 1 + 0.5) \times |R_y| = (H - 0.5) \times |R_y|$ となります。

## ✨ 主な機能

- 📂 **統合ドラッグ＆ドロップ対応**:
  - 地図画像（`.png`, `.pgm`, `.jpg` 等）とワールドファイル（`.pgw`, `.wld`）を同時に（または個別に）ドロップ可能。
- 🖼️ **画像サイズ自動取得**:
  - PNG/JPG等の標準形式はもちろん、ROSで標準的な **PGM（Netpbm P2 / P5 バイナリ）** もブラウザ側で直接バイナリ解析し、幅・高さを自動取得＆Canvasプレビュー表示。
- 📝 **柔軟な入力・手動微調整**:
  - ファイル読み込みによる自動反映に加え、各パラメータの手動編集やPGW生テキストの直接ペーストにも即時連動。
- ⚡ **リアルタイム計算 & 展開過程の可視化**:
  - パラメータ変更と同時に $origin\_x$, $origin\_y$, $resolution$ を再計算し、数式の代入ステップを表示。
- ⚙️ **Nav2 追加オプション設定**:
  - `image`: 出力画像ファイル名
  - `negate`: 白黒反転（`0` / `1`）
  - `occupied_thresh` / `free_thresh`: スライダー連動の閾値設定
  - `mode`: マップモード（`trinary`, `scale`, `raw`, またはROS 1互換の非出力）
  - 精度設定: スマート自動（丸め誤差除去）/ 小数点6桁 / 生値
- 📋 **出力・エクスポート**:
  - ワンクリックでクリップボードへコピー（トースト通知付き）
  - `map.yaml` ファイルの直接ダウンロード
- ⚠️ **自動エラー・警告検知**:
  - PGWの回転パラメータ（$A \neq 0$ または $B \neq 0$）が含まれる場合の警告通知
  - 縦横アスペクト比不一致（$|R_x| \neq |R_y|$）の検知・警告
- 💡 **デモデータ即時読込**:
  - 典型的なUTM座標系高精度マップのデモデータをワンクリックでセット可能。

## 🚀 使い方

### 1. 起動方法
ビルドやサーバー起動は不要です。

```bash
# ブラウザで index.html を直接開くだけ
google-chrome index.html
# または
firefox index.html
```

### 2. 操作手順
1. **ファイル投入**:
   - QGIS等からエクスポートした画像（`map.png` または `map.pgm`）とワールドファイル（`map.pgw`）を画面上部のドロップゾーンにドラッグ＆ドロップします。
2. **パラメータ確認・オプション調整**:
   - 自動抽出された画像サイズ $(W, H)$ や解像度、座標値を確認します。
   - 必要に応じて `negate` や `occupied_thresh` などの閾値を調整します。
3. **出力**:
   - 生成された `map.yaml` プレビューを確認し、「**コピー**」または「**map.yaml をダウンロード**」をクリックして保存します。

## 📄 出力される YAML 例

```yaml
image: tsukuba_challenge_map.png
mode: trinary
resolution: 0.05
origin: [392500, 3954050.05, 0.0]
negate: 0
occupied_thresh: 0.65
free_thresh: 0.25
```

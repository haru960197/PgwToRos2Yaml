# PgwToRos2Yaml

> **QGIS World File (`.pgw`) ⇄ ROS / ROS 2 (Nav2) `map.yaml` & `utm_to_map.yaml` Converter**  
> QGIS等のGISソフトウェアから出力されたワールドファイル（PGW形式）と地図画像情報をもとに、ROS / ROS 2 の `map_server`（Nav2等）で使用する **`map.yaml`（原点 [0,0,0] 固定）** と **`utm_to_map.yaml`（UTM原点オフセット）** を自動計算・出力するスタンドアロンWebツールです。

---

## 📌 概要

屋外自律移動ロボットや測量・GIS連携において、QGIS等で作成した高精度なオルソ画像や地図データ（UTM座標系等）を ROS / Nav2 に取り込む際、以下の2つの課題が頻繁に発生します：

1. **原点定義の違い**:
   - PGW形式は「**左上ピクセル中心**」が基準。
   - ROS `map_server` は画像の「**左下ピクセル外側角（境界）**」が基準。
2. **巨大な座標値による数値精度問題**:
   - UTM座標値（例: $X = 392,500\text{ m},\ Y = 3,954,000\text{ m}$）をそのまま `map_server` の `origin` に設定すると、RViz等の描画（単精度浮動小数点 float32）や TFツリー（`map -> odom -> base_link`）上で**桁落ちによる表示ジッターや誤差**が生じます。

本ツールは、このベストプラクティスに基づき：
- **`map.yaml`**: 原点をローカル基準 **`[0.0, 0.0, 0.0]`** に固定して出力
- **`utm_to_map.yaml`**: 計算された真のUTM原点オフセットを **ROS 2 パラメータファイル形式** で出力

の2ファイルを一括で自動生成します。

## 📄 各出力ファイルの仕様

### 1. `map.yaml`（map_server / Nav2 用）
地図画像と解像度を定義し、原点はローカル原点 `[0.0, 0.0, 0.0]` に固定します。

```yaml
image: map.png
resolution: 0.05
origin: [0.0, 0.0, 0.0]
negate: 0
occupied_thresh: 0.65
free_thresh: 0.25
```
*(※ Nav2 拡張用の `mode: trinary` もオプション選択可能です)*

### 2. `utm_to_map.yaml`（UTM ⇄ map 座標変換ノード用）
PGWから計算された高精度なUTM座標系の原点オフセットを保持する ROS 2 パラメータファイルです。

```yaml
/**:
  ros__parameters:
    map_origin_utm:
      x: 392500.0
      y: 3954050.05
      z: 0.0
      yaw: 0.0
```

## 📐 座標系と原点の変換仕様（数学的根拠）

### 1. PGWファイル（ワールドファイル）の構造（6行）

| 行 | パラメータ | 説明 | 典型的な値 |
|:---:|:---:|:---|:---|
| 1 | $R_x$ | X方向のピクセル解像度 [m/pixel] | `0.05` |
| 2 | $A$ | 回転パラメータ（通常 0） | `0.0` |
| 3 | $B$ | 回転パラメータ（通常 0） | `0.0` |
| 4 | $R_y$ | Y方向のピクセル解像度（上から下へ進むため通常**負値**） | `-0.05` |
| 5 | $X_{\text{pgw}}$ | **左上ピクセル中心**のX座標（UTM Easting等 [m]） | `392500.025` |
| 6 | $Y_{\text{pgw}}$ | **左上ピクセル中心**のY座標（UTM Northing等 [m]） | `3954200.025` |

### 2. 幾何学的関係とオフセット計算

```
[PGWの基準点]
(X_pgw, Y_pgw) ─── 左上ピクセル中心
      │
      │ ＋0.5 * |Rx| (左端境界へ半ピクセル戻す)
      ▼
┌──────────────┐
│  左上ピクセル  │ ...
├──────────────┤
│              │
│   地図画像    │ 高 さ H (pixels)
│              │
├──────────────┤
│  左下ピクセル  │ ...
└──────────────┘
▲
│
[真の地図原点 (UTM)]
(origin_x, origin_y) ─── 左下ピクセル外側角 (境界)
```

画像の幅を $W$、高さを $H$（ピクセル単位）とした場合の計算式：

$$resolution = |R_x|$$

$$origin\_x = X_{\text{pgw}} - \frac{|R_x|}{2}$$

$$origin\_y = Y_{\text{pgw}} - (H - 0.5) \times |R_y|$$

> **【補足】Y方向の導出理由**:
> 1. 左上ピクセル中心 ($Y_{\text{pgw}}$) から 左下ピクセル中心 までは $(H - 1)$ ピクセル下方に移動します。
> 2. 左下ピクセル中心 から 左下ピクセルの外側角（下端境界） までは さらに $0.5$ ピクセル下方に移動します。
> 3. したがって、合計移動量は $(H - 1 + 0.5) \times |R_y| = (H - 0.5) \times |R_y|$ となります。

## ✨ 主な機能

- 📂 **統合ドラッグ＆ドロップ対応**:
  - 地図画像（`.png`, `.pgm`, `.jpg` 等）とワールドファイル（`.pgw`, `.wld`）を同時に（または個別に）ドロップ可能。
- 🖼️ **画像サイズ自動取得**:
  - PNG/JPG等の標準形式に加え、ROSで定番の **PGM（Netpbm P2 / P5 バイナリ）** もブラウザ側で直接バイナリ解析し、幅・高さを自動取得＆Canvasプレビュー表示。
- 📑 **デュアルタブ リアルタイムプレビュー**:
  - `map.yaml` と `utm_to_map.yaml` をタブでワンクリック切り替え可能。
  - シンタックスハイライトによる見やすい表示。
- 💾 **個別＆一括ダウンロード**:
  - 「`map.yaml` を保存」
  - 「`utm_to_map.yaml` を保存」
  - 「2ファイルを一括ダウンロード」
- 📋 **クリップボードコピー**:
  - 現在表示中のタブのYAMLを即座にコピー（トースト通知付き）。
- ⚠️ **自動エラー・警告検知**:
  - PGWの回転パラメータ（$A \neq 0$ または $B \neq 0$）が含まれる場合の警告通知。
  - 縦横アスペクト比不一致（$|R_x| \neq |R_y|$）の検知・警告。
- 💡 **デモデータ即時読込**:
  - 典型的な高精度GISマップ（つくばチャレンジ等の屋外環境を想定）のデモデータをワンクリックでセット可能。

## 🚀 使い方

### 1. 起動方法
外部サーバーやビルド手順は不要です。

```bash
# ブラウザで index.html を直接開くだけ
google-chrome index.html
# または
firefox index.html
```

### 2. 操作手順
1. **ファイル投入**:
   - 地図画像（`map.png` または `map.pgm`）とワールドファイル（`map.pgw`）をドロップゾーンに投入します。
2. **パラメータ確認・オプション調整**:
   - 自動抽出されたサイズ $(W, H)$ や解像度、展開された計算式を確認します。
   - `occupied_thresh` や `free_thresh` などの閾値を必要に応じて調整します。
3. **エクスポート**:
   - タブで `map.yaml` と `utm_to_map.yaml` を確認し、「**一括ダウンロード**」または個別ダウンロードボタンをクリックします。
